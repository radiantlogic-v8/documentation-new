## Security Vulnerability Fixes

This hotfix updates our container images and third‑party libraries to remediate multiple security vulnerabilities, including several high‑ and critical‑severity CVEs. It does not introduce new features or functional changes and is recommended for all customers to improve overall security posture.

- [API-4324]: Fix to address CVE-2026-24281, CVE-2026-24308, CVE-2026-22732,CVE-2026-27830, CVE-2026-27727, CVE-2026-24400, CVE-2025-67030, CVE-2026-24734, CVE-2025-66614 and CWE-770.
- [API-4334]: Fix to address CVE-2026-4800, CVE-2026-33671 and CVE-2026-33750.
- [API-4335]: Fix to address CVE-2026-26996, CVE-2026-27903 and CVE-2026-27904.
- [API-4336]: Fix to address CVE-2023-24998.
- [API-4338]: Fix to address CVE-2026-33870 and CVE-2026-33871.
- [API-4348]: Fix to address CVE-2026-4046.

- Updated container base images to include latest OS security patches addressing multiple high and critical severity CVEs.
- Upgraded third‑party libraries (e.g., Spring, Netty, Tomcat) to versions that fix known vulnerabilities addressing multiple high and critical severity CVEs.
