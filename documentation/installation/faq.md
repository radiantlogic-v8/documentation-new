## Self-managed FAQs

This document outlines frequently asked questions regarding platform compatibility and supported environments for **self-managed** Identity Data Management Version 8 (v8) deployments. <br> <br>

1. **Does self-managed v8 support both Linux and Windows operating systems?** 

     No. Self-managed v8 deployments are supported only on **Linux-based** operating systems.

2. **Is AMD64 architecture supported?** <br>

     Yes. Self-managed v8 deployments support **AMD64** architecture.

3. **Which Kubernetes platforms are supported?** 

     Self-managed v8 supports deployment on:
     - **Upstream Kubernetes (K8s)**
     - **Red Hat OpenShift**
     
     Deployments on managed Kubernetes services such as **EKS**, **AKS**, or **GKE** are supported and may require
     environment-specific configuration or adjustments depending on the cloud provider.

4. **Are both v7 and v8 supported for self-managed deployments**? 

     Self-managed deployments are supported only in Version 8 (v8).
